# Локальный динамический анализатор отклонений дентальных имплантов

Система для сравнения плана имплантации (RealGUIDE STL + Pre-op КТ) с фактическим результатом после операции (Post-op КТ).

## Структура папки
- `implant_analyzer.py` — основной файл анализатора.
- `requirements.txt` — зависимости Python.

## Установка окружения

Рекомендуется Python 3.9 - 3.11:

```bash
pip install -r requirements.txt
```

## Как запустить

В блоке `if __name__ == "__main__":` в файле `implant_analyzer.py` укажите пути к вашим данным:
- `PRE_DICOM_DIR` — папка с DICOM файлами предоперационного КТ.
- `POST_DICOM_DIR` — папка с DICOM файлами постоперационного КТ.
- `PLANNED_STLS` — список путей к STL-файлам запланированных имплантов.

Запуск:
```bash
python implant_analyzer.py
```

## Что реализовано:
1. **Жесткая 3D-регистрация (SimpleITK)**: Автоматическое совмещение челюстей до и после вмешательства (Mattes Mutual Information).
2. **Локальный ICP-фиттинг (Open3D)**: Фактические импланты ищутся в целевых ROI с порогом плотности титана (HU > 2800), что исключает артефакты и помехи от соседних коронок.
3. **Клинические метрики**:
   - Точка входа (Coronal 3D, мм)
   - Апекс (Apical 3D, мм)
   - Угол наклона оси (градусы)
   - Глубина погружения (Depth, мм)
   - Латеральное смещение (Lateral, мм)
4. **Анализ причин («Почему?»)**:
   - Недопогружение / провал стоппера.
   - Механический люфт втулки шаблона.
   - Увод апекса по кортикальной пластинке.
5. **[Пункт 2] Мульти-имплантный анализ поведения шаблона (All-on-X / 2+ импланта)**:
   - Алгоритм Кабша (Kabsch SVD) для выявления истинного сдвига/перекоса шаблона как единого твердого тела.
   - Расчет степени сонаправленности векторов смещения.
   - Точный вердикт: вызвана ли ошибка недопосадкой/качанием шаблона или индивидуальным сверлением.
